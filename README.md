# 🏫 BioClass VR: ห้องเรียนและห้องปฏิบัติการชีววิทยาเสมือนจริง 3D & WebVR

**BioClass VR** เป็นสื่อการเรียนรู้และเกมจำลองห้องปฏิบัติการชีววิทยาเสมือนจริง (Virtual Reality & 3D Interactive Classroom) ที่สมจริงเสมือนอยู่ในห้องเรียนวิทยาศาสตร์จริง รองรับการใช้งานผ่านแว่น VR (Meta Quest, Apple Vision Pro, Pico) และคอมพิวเตอร์ทั่วไป

---

## 🏫 บรรยากาศห้องเรียนชีววิทยาสมจริง (Classroom Environment)
* **กระดานดำ/ไวท์บอร์ดหน้าห้องเรียน (Interactive Classroom Blackboard):** มีเนื้อหาและแผนการสอนประจำคาบเรียน สามารถคลิกปุ่ม **"เปลี่ยนสไลด์ ❯"** บนกระดานเพื่อเปลี่ยนหน้าบทเรียน (วัตถุประสงค์แล็บ, ทฤษฎีออสโมซิส, โครงสร้างเซลล์)
* **นาฬิกาแขวนผนังห้องเรียน & หน้าต่างรับแสงธรรมชาติ:** หน้าต่างบานใหญ่พร้อมแสงแดดธรรมชาติส่องเข้ามาในห้องเรียน พร้อมวิวต้นไม้รอบรั้วโรงเรียน
* **โต๊ะปฏิบัติการไม้ยาวประจำกลุ่มนักเรียน (Wood Pod Benches):** พร้อมเก้าอี้หมุนแล็บ (Lab Stools), อ่างล้างแก้ว และก๊อกน้ำโครเมียมประจำโต๊ะ
* **ตู้กระจกเก็บตัวอย่างชีววิทยา (Specimen Display Cabinet):** บรรจุขวดโหลตัวอย่างดอง พืช สัตว์ทะเล
* **มุมกายวิภาค (Anatomy Corner):** หุ่นจำลองกายวิภาคอวัยวะภายใน (Torso Model) และโครงกระดูกจำลอง (Skeleton Stand)
* **โปสเตอร์การศึกษาประจำห้องแล็บ:** โปสเตอร์เปรียบเทียบเซลล์พืช-สัตว์ และกฎความปลอดภัยในห้องปฏิบัติการวิทยาศาสตร์

## 🔬 การทดลองที่สมจริง (Realistic Hands-on Experiments)
1. **กล้องจุลทรรศน์จริงและการเอาตาไปส่องที่เลนส์ (True Ocular Eyepiece Immersion):**
   * **เลนส์แก้วจริงบนตัวกล้อง (Physical Optical Eyepiece Lens):** ที่หัวกล้องจุลทรรศน์ 3D ตัวเลนส์ใกล้ตาทั้งสองข้างมีการฉายภาพตัวอย่างเซลล์สดทะลุผ่านเนื้อแก้วจริง แม้มองจากภายนอก
   * **แอนิเมชันก้มส่องกล้อง (Eyepiece Lean-in Animation):** คลิกที่หัวกล้องหรือกดปุ่ม **"👁️ ก้มส่องกล้อง"** ผู้เล่นจะก้มโน้มตัวเอาดวงตาแนบชิดกับยางครอบเลนส์ใกล้ตา เข้าสู่วงเลนส์กล้องจุลทรรศน์เสมือนจริง (Binocular Rubber Eyecup View)
   * **การเลื่อนแท่นสไลด์สำรวจเซลล์ (Mechanical Stage Pan X/Y):** ขณะส่องกล้อง สามารถลากเมาส์บนเลนส์ หรือกดปุ่มลูกศรเพื่อเลื่อนสไลด์ค้นหาเซลล์ในตำแหน่งต่างๆ
   * **การปรับระยะโฟกัสลึก-ตื้น (Coarse & Fine Focus):** หมุนลูกกลิ้งเมาส์ หรือกดปุ่ม `+ / -` เพื่อปรับภาพจากเบลอไปจนถึงคมชัดสมบูรณ์แบบ
   * **สเกลไมโครมิเตอร์วัดขนาดเซลล์ (Ocular Micrometer):** เปิดสเกลไม้บรรทัดไมครอน ($\mu m$) ทาบบนตัวอย่างเพื่อวัดขนาดจริงของเซลล์
   * **ม่านปรับแสงไดอะแฟรม (Iris Diaphragm):** ปรับความสว่างและ Contrast ของแสงที่ส่องผ่านเยื่อหุ้มเซลล์
   * **ระบบบันทึกภาพลงสมุดแล็บ (Snapshot to Lab Report):** ถ่ายภาพเซลล์ที่ส่องเห็นจริงเก็บไว้ในสมุดรายงานผลการทดลอง
   * **ปุ่มเงยหน้าถอยออกจากกล้อง (Step Back):** กด **"⬅️ เงยหน้าถอยออกจากกล้อง"** มุมมองจะถอยกลับมายืนหน้าโต๊ะแล็บอย่างนุ่มนวล
   * สวิตช์เปิด-ปิดไฟส่องกล้อง (Illuminator Power Switch)
   * ปิเปตต์หยดสีย้อม (Interactive Dropper Animation) เคลื่อนที่มาหยดสารละลายลงบนสไลด์จริง
2. **ระบบภารกิจการทดลองชีววิทยา 7 ขั้นตอน (Interactive Lab Quest):**
   * มีแถบ Checklist ตรวจสอบขั้นตอนการทำแล็บจริงอัตโนมัติ (วางสไลด์ $\rightarrow$ ย้อมสี $\rightarrow$ เปิดไฟ $\rightarrow$ ก้มส่องกล้อง $\rightarrow$ โฟกัส $\rightarrow$ เพิ่มกำลังขยาย $\rightarrow$ บันทึกผล) พร้อมเสียงและแถบความคืบหน้าแบบ Real-time
3. **การทดลองออสโมซิส:**
   * บีกเกอร์แก้วบรรจุสารละลาย Hypotonic, Isotonic, Hypertonic
   * ปรากฏการณ์ Plasmolysis และ Lysis จำลองแบบ Progressive Kinetics ค่อยๆ พองหรือเหี่ยวสมจริง
   * ซูมดูเยื่อหุ้มเซลล์และโมเลกุลน้ำ $H_2O$ ผ่านช่อง Aquaporin
4. **การย่อส่วนทะลุเข้าสู่ภายในเซลล์ 3D (Sub-Cellular Dive):**
   * ทดลองผลิต ATP จากไมโทคอนเดรีย, สำรวจเกลียวคู่ DNA, และสังเคราะห์ด้วยแสงในคลอโรพลาสต์

## 🔬 จุดเด่นและการทดลองจำลองเสมือนจริง (Interactive Experiments)

### 1. สถานีกล้องจุลทรรศน์จำลอง (Virtual Compound Light Microscope)
* **กล้องจุลทรรศน์ 3D สมจริง:** ปรับเลนส์ใกล้วัตถุ (Objective Lenses: 4x, 10x, 40x, 100x), หมุนปุ่มปรับภาพหยาบ/ละเอียด (Coarse & Fine Focus) ซึ่งส่งผลต่อความคมชัด (Depth of Field Blur) แบบเรียลไทม์
* **ตัวอย่างสไลด์สิ่งมีชีวิตชีววิทยา (Specimens):**
  1. **เซลล์เยื่อหอม (Onion Epidermal Cells):** สังเกตผนังเซลล์ (Cell Wall), ไซโทพลาซึม และแวคิวโอลขนาดใหญ่
  2. **เซลล์เยื่อบุข้างแก้ม (Human Cheek Cells):** สังเกตเซลล์สัตว์รูปทรงไม่แน่นอน และนิวเคลียสกลม
  3. **สเมียร์เลือดมนุษย์ (Human Blood Smear):** เม็ดเลือดแดง (RBC - Biconcave Disc) และเม็ดเลือดขาว (WBC - นิวเคลียสหลายพู)
  4. **สิ่งมีชีวิตเซลล์เดียว (Living Paramecium):** พารามีเซียมว่ายน้ำได้แบบมีชีวิต พร้อมขนซิเลีย (Cilia) และคอนแทร็กไทล์แวคิวโอล
* **การย้อมสีสไลด์ (Staining Lab):** มีขวดสารละลายไอโอดีน (Iodine) และเมทิลีนบลู (Methylene Blue) เพื่อดูการติดสีของนิวเคลียสและโครงสร้างเซลล์

---

### 2. สถานีการทดลองออสโมซิสและแรงดันเต่ง (Osmosis & Tonicity Chamber)
* **การเปรียบเทียบใน 3 สารละลาย:**
  * **Hypotonic Solution (น้ำกลั่น):** น้ำออสโมซิสเข้าสู่เซลล์ $\rightarrow$ เซลล์สัตว์แตกออก (Cell Lysis) / เซลล์พืชเต่ง (Turgid) ไม่แตกเพราะมีผนังเซลล์
  * **Isotonic Solution (0.9% Normal Saline):** สมดุลน้ำเข้า-ออกคงที่
  * **Hypertonic Solution (10% NaCl):** น้ำออสโมซิสออกจากเซลล์ $\rightarrow$ เซลล์สัตว์เหี่ยวหยักย่น (Crenation) / เซลล์พืชเกิดพลาสโมไลซิส (Plasmolysis)
* **Aquaporin Molecular View:** ซูมดูเยื่อหุ้มเซลล์ (Phospholipid Bilayer) และโมเลกุลน้ำ ($H_2O$) ที่แพร่ผ่านช่องโปรตีน Aquaporin ตามความแตกต่างของชลศักย์ (Water Potential)

---

### 3. สถานีย่อส่วนสำรวจภายในเซลล์ 3D (Sub-Cellular VR Dive)
* ย่อส่วนผู้เล่นเดินทางเข้าไปสู่ภายในเซลล์ยูคาริโอต (Eukaryotic Cell) ลอยอยู่ท่ามกลางโครงร่างค้ำจุนเซลล์ (Cytoskeleton) และไรโบโซม
* **ไมโทคอนเดรีย (Mitochondria):** กดปุ่มป้อน Glucose + $O_2$ เพื่อกระตุ้นเอนไซม์ ATP Synthase ผลิตโมเลกุลพลังงาน ATP เปล่งแสงระยิบระยับ
* **นิวเคลียสและรหัสพันธุกรรม (Nucleus & DNA):** ส่องทะลุรูพรุนนิวเคลียสเข้าไปดูเกลียวคู่ดีเอ็นเอ (DNA Double Helix) พร้อมคู่เบส A-T, C-G
* **คลอโรพลาสต์ (Chloroplast):** สลับแสงแดด (Sunlight) เพื่อสังเกตการสังเคราะห์ด้วยแสง ปลดปล่อยฟองก๊าซออกซิเจน ($O_2$)
* **กอลจิคอมเพล็กซ์ (Golgi Apparatus):** ดูการลำเลียงถุง Vesicles ไปตามรางไมโครทูบูล

## 🚀 วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: รันด้วย Python Server (แนะนำ สะดวกที่สุด)
เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์คำสั่ง:
```bash
python3 server.py
```
หรือ
```bash
npm start
```
เปิดเบราว์เซอร์ไปที่: **`http://localhost:8080`**

### วิธีที่ 2: เปิดบนแว่น VR (Meta Quest 2 / 3 / Pro, Apple Vision Pro, Pico)
1. เปิดแว่น VR และเชื่อมต่อ Wi-Fi วงเดียวกับคอมพิวเตอร์ของคุณ
2. ดู IP address ของเครื่องคอมพิวเตอร์ เช่น `http://192.168.1.xxx:8080`
3. เปิด Browser ในแว่น VR แล้วพิมพ์ URL ดังกล่าว
4. กดปุ่ม **`ENTER VR`** ที่มุมขวาล่างของจอภาพเพื่อเข้าสู่โลกเสมือนจริงทันที!

## 🎮 การควบคุม (Controls)

| อุปกรณ์ | การควบคุม |
| :--- | :--- |
| **แว่น VR (WebXR)** | • **เดินในห้อง (Smooth Locomotion):** โยก Thumbstick ก้านโยกที่คอนโทรลเลอร์มือซ้ายเพื่อเดินตามทิศทางที่มอง<br>• **หันมุมกล้อง (Snap Turn):** โยก Thumbstick คอนโทรลเลอร์มือขวาเพื่อหมุนมุมมอง 45°<br>• **เทเลพอร์ต (Floor Teleport):** ชี้ลำแสงเลเซอร์ไปที่พื้น จะมีวงแหวนสีฟ้าปรากฏ แล้วกดยิง Trigger เพื่อเทเลพอร์ตไปยังจุดนั้นทันที<br>• **โต้ตอบอุปกรณ์:** ชี้เลเซอร์ไปที่กล้องจุลทรรศน์, บีกเกอร์, แผ่นสไลด์, สีย้อม แล้วกดยิง Trigger |
| **เมาส์และคีย์บอร์ด (Desktop)** | • **เดินในห้อง (WASD Walking):** กดปุ่ม `W, A, S, D` หรือ `ปุ่มลูกศร` เพื่อเดินสำรวจห้องแล็บได้อย่างอิสระ<br>• **วิ่งเร็ว (Sprint):** กดปุ่ม `Shift` ค้างไว้ขณะเดิน<br>• **ปุ่มเดินบนหน้าจอ (Virtual D-Pad):** มีปุ่มลูกศรที่มุมซ้ายล่างสำหรับคลิกหรือทัชสกรีนเดิน<br>• **หมุนมุมมอง 360°:** คลิกซ้ายค้าง + ลากเมาส์<br>• **ซูมเข้า-ออก:** สกอร์ลลูกกลิ้งเมาส์<br>• **คลิกที่อุปกรณ์ 3D:** โต้ตอบกับสไลด์, บีกเกอร์, ปุ่มควบคุม, ขวดสีย้อม |

## 🛠️ สถาปัตยกรรมเทคโนโลยี (Tech Stack)
* **Three.js (r160):** 3D WebGL Graphic Rendering Engine
* **WebXR API:** มาตรฐาน VR Immersive Session รองรับคอนโทรลเลอร์และการตรวจจับการเคลื่อนไหว
* **Web Audio API:** ระบบสังเคราะห์เสียงบรรยากาศห้องแล็บ เสียงคลิกกลไก เสียงหยดสาร และเสียงพัลส์พลังงานแบบ procedural โดยไม่ต้องโหลดไฟล์ภายนอก
* **Canvas Procedural Textures:** สร้างภาพเซลล์จุลทรรศน์คมชัดระดับ HD
